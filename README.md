# Vivaldi Custom CSS

My custom CSS for the [Vivaldi](https://vivaldi.com) browser.

## Usage

1. Clone the repo to a local directory
2. Open Vivaldi settings > Appearance
3. Under Custom UI Modifications, select the repo directory
4. Restart Vivaldi
